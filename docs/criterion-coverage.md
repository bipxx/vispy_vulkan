expected behavior, exact fixture node/case count/source hash and partial links

## Review and identity

The map pins the candidate scope digest, which excludes only its reviews and
self identity. The same existing scope review can bind both candidate and map
through candidate_scope_sha256 and coverage_map_sha256. Adding the review refs
therefore creates no digest cycle. Source and scope reviews still both need to
pass. A map change invalidates coverage approval; a relevant candidate input
change invalidates its scope binding. These are content-binding checks, not
authentication of a reviewer's independence. Current real reviews remain null.

Both declarations must validate for the future artifact qualification index;
that index must require the selected reviewed criterion bindings and their
profile-local dependency closure. All required selected branches are conjunctive.
A valid proposal or a reviewed map still cannot admit a wheel, qualify a profile,
waive the mandatory host matrix or finish full inventory reconciliation.
