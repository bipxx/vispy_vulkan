# R2 release assembly and W11 publication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish `vispy 0.17.0+vulkan.1`: fresh cp312 wheels for Windows and Linux, built from the final source, with
every mandatory row requalified on them, then a GitHub Release and a PEP 503 index.

**Architecture:** One final source S on the branch `r2/release`: the R2 integration branch (`r2/integration-287`) with
`main` merged in, plus the record renewals that CI validates. The wheels are built fresh from S (D1), qualified as the
release artifacts, and bound into the records before final-head CI and the promotion review. Each phase is its own
registered run.

**Spec:** the consolidated plan's R2, W11 and W15 rows and decisions D1, D2, D18, D31, D32, D33, D34, D35 and D36.
The user, 2026-11-04: "approve" (publish once R2's gates pass), then cp312 Windows + Linux only, a manylinux_2_38
Linux tag and the index on this repository's GitHub Pages.

## Global Constraints

- **Minimal, clean and principled** (Standing rules): no step that the decisions do not require; one record per fact.
- **Other owners.** `r2/pending-runtime-patches` and `r2/integration-287` stay as they are; S is a new branch. The
  publication clone's main worktree stays on its owner's branch.
- **Retained files are never edited** (the plan's Standing rules); pinned records are renewed only through their own
  tools or a reviewed renewal script, and each renewal is checked by the validator that reads it.
- **Evidence.** Expectations are written before measuring; failures are kept, never relabeled; no skip or xfail.
- **Hygiene** (AGENTS.md): every phase registers its run; scratch only in `build/work/<run-id>`; each run is closed with
  retention, a cleanup plan, apply and audit before the next starts.
- **No preview** (D2): nothing is published, and no release or index is created, before Phase 5 passes.
