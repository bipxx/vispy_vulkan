# Installed-wheel scalar and categorical volumes

Deliver all eleven original scalar and six categorical napari volume workflows
from clean installed-wheel environments, in separately waited workers. Preserve
both original fixture modules, manifest/reference bytes, source hashes and
comparison rules. Scalar cases retain their fixed analytic masks, maximum
interior error 2 and at most 0.001 differing fraction in the checked edge region.
Categorical cases retain exact full RGBA and the original native-widget check.
Every original parameter, quality setting, sparse label ID and input revision
must match. The edge region is checked, never excluded from comparison.

1. Pin both original manifests and verify all original artifact, fixture/capture,
   host-lock, landmark, method/mode, input and license joins without graphics.
2. Add isolated external wheel consumers with locked runtime and hosts installed
   together with the exact hashed candidate wheel. Retain observed launch IDs,
   actual worker termination, package/native byte origins, backend/device and
   eight zero-resource shutdown counters. Unknown worker termination blocks
   further launches and environment removal.
3. Freeze sources and reference bindings, run provider-free controls and exact
   seventeen-case collection, then use independent read-only peer review before
   running graphics. Preserve every failed attempt; never overwrite evidence.
4. Exercise the archived audited Windows CPython 3.12 wheel on hardware Vulkan,
   independently verify saved full images/parameters/native/cleanup evidence,
   document the bounded result and publish the tested regressions. Remove only
   newly owned temporary environments after their actual workers are terminal.

This does not close Glue's separate volume discrepancy, other host/plugin rows,
smooth lines, physical Qt lifecycle matrices, other ABIs/platforms, fresh build,
performance or complete release qualification. All original release requirements
remain in scope. Cybersecurity work is excluded. Both the implementation AGPL
and original BSD licenses and third-party notices remain attached unchanged.
